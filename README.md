# Alerivex Public Landing Bundle

This directory is generated by `npm run landing:export`.

Use it as the content for your public landing repository.
Recommended repository model:
- private repo: full app, backend, docs, release assets
- public repo: landing only

Before publishing:
- replace `YOUR_PUBLIC_ICON_URL` in `store-buttons.html` and `store-buttons-en.html`
- configure your actual store links in `index.html` if placeholders are still present
- make sure your GitHub Pages or other public hosting URL is final
